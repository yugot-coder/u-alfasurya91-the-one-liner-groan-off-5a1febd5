# The One-Liner Groan-Off

One original dad joke, written to be told out loud at the dinner table —
a hammer in the fridge, and a pun that fires twice.

> I keep a hammer in the fridge so I can nail the cold cuts.

58 characters, one line. The setup is a single odd image; the punchline
is a double pun in the last four words — *nail* (what a hammer does) and
*cold cuts* (the deli meat that lives in the fridge). See
[CANDIDATES.md](CANDIDATES.md) for the ten candidates considered and why
this one won.

## Run

```sh
python3 main.py
```

Writes the joke to `<MAKEFUN_OUTPUT_DIR>/entry.txt` (default
`/output/entry.txt`), then reads it back and validates it (1–140
characters, one line, not only whitespace). Standard library only,
deterministic, no network.
